# Saga Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A per-project Saga (spec section 11, formerly "the Hearth"): plain Markdown under `.hulder/` holding Tales (tickets), Verses (TODO checkboxes) and Lore (notes), a right-dock `SagaPanel` that lists and edits them, a one-time "Keep in git / Local only" choice, and two herdr handoffs (`saga::SendToAgent`, `saga::StartAgentOnTale`).

**Architecture:** One new crate `saga` with three modules. `model.rs` is pure string and path logic (front matter, slugs, ids, checkbox lists, lore listing, `AGENTS.md` template) with no I/O and no gpui. `store.rs` is async file I/O over `&dyn fs::Fs` on paths under `<root>/.hulder/`, still with no gpui types, so Bifröst (`crates/bifrost`) can reuse both from a non-UI crate. `panel.rs` is the only gpui code: the `workspace::Panel`, the title prompt modal, the first-use notification, the project-event watch, and the herdr calls through `herdr::HerdState::global(cx).read(cx).client()`.

**Tech Stack:** Rust, gpui, `fs::Fs` (`FakeFs` in tests), `workspace::{Panel, ModalView, Toast}`, `workspace::notifications::simple_message_notification::MessageNotification`, `herdr::HerdrClient::request`, `herd_panel::HerdView`, `chrono` for dates.

**Spec:** `docs/superpowers/specs/2026-10-13-hulder-design.md`, section 11 (and 5 for herdr).

## Naming

| Spec word | UI word | Code |
|---|---|---|
| ticket | Tale | `Tale`, `tickets/NNNN-slug.md` |
| todo | Verse | `Verse`, `TODO.md` |
| note | Lore | `NOTES.md`, `notes/YYYY-MM-DD.md` |
| `## Log` | `## Chronicle` | `Tale::append_chronicle` |
| `hearth.json` | | `.hulder/saga.json` |

File layout under `.hulder/` is unchanged from the spec: `NOTES.md`, `TODO.md`, `tickets/`, `AGENTS.md`, plus `notes/` and `saga.json`.

## Global Constraints

- `model.rs` and `store.rs` contain no gpui types. Store methods take `&dyn Fs` and plain paths/strings.
- Front matter is a fixed key set (`id`, `title`, `status`, `priority`, `tags`, `created`, `updated`) hand-parsed; unknown keys are kept verbatim so a round trip never drops data.
- `TODO.md` rewrites preserve every non-checkbox line byte for byte.
- `.hulder/bin/` is always excluded through `.git/info/exclude`; `.hulder/` is excluded only when `tracked == false`. Exclude lines are appended once, never duplicated, and only when `.git/info/exclude` already exists.
- herdr request shapes (from `herdr api schema --json`): `workspace.create` params `{cwd, label, focus}` replies `{"type":"workspace_created","workspace":{"workspace_id":...},"tab":...,"root_pane":...}`; `agent.start` params `{name, argv}` required plus `{cwd, workspace_id, focus}` replies `{"type":"agent_started","agent":{"terminal_id":...}}`; `agent.send` params `{target, text}` replies `{"type":"ok"}`.
- Follow repo CLAUDE.md: no `unwrap()` outside tests, no `let _ =`, no `mod.rs`, `./script/clippy`, README marker stays.

## Review Focus

1. Front matter round trip: parse then serialize must reproduce the input, including a title containing `: ` and a `tags: []` line. Tests in Task 1.
2. Next id with gaps and foreign files: `0001-a.md`, `0007-b.md`, `README.md` gives `8`; empty gives `1`. Test in Task 1.
3. Verse toggle must only touch the one line and keep nested indentation. Test in Task 2.
4. First write without `.git/info/exclude`: the store must not create the file. Test in Task 4.
5. `StartAgentOnTale` when the `workspace.create` reply lacks `workspace.workspace_id`: must surface an error toast, not start an agent in a random workspace. Test in Task 7 (`workspace_id_from_create_reply`).

`model.rs` core:

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub enum Status { Open, Doing, Blocked, Done }
impl Status {
    pub const ALL: [Status; 4] = [Status::Open, Status::Doing, Status::Blocked, Status::Done];
    pub fn as_str(self) -> &'static str { ... }
    pub fn parse(text: &str) -> Option<Self> { ... }
    pub fn next(self) -> Self { open→doing→blocked→done→open }
}
pub enum Priority { Low, Normal, High }  // next: low→normal→high→low

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Tale {
    pub id: u32, pub title: String, pub status: Status, pub priority: Priority,
    pub tags: Vec<String>, pub created: String, pub updated: String,
    /// Front matter lines we do not understand, kept for the round trip.
    pub extra: Vec<String>,
    pub body: String,
}
impl Tale {
    pub fn new(id: u32, title: &str, today: &str) -> Self;   // body = "\n## Chronicle\n- {today} created\n"
    pub fn parse(text: &str) -> anyhow::Result<Self>;
    pub fn serialize(&self) -> String;
    pub fn file_name(id: u32, slug: &str) -> String;           // format!("{id:04}-{slug}.md")
    pub fn append_chronicle(&mut self, line: &str);            // creates "## Chronicle" if missing
    pub fn touch(&mut self, today: &str);                      // updated = today
}
pub fn slugify(title: &str) -> String;
pub fn next_id<'a>(file_names: impl IntoIterator<Item = &'a str>) -> u32;
```
