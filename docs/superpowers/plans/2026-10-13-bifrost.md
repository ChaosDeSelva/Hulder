# Bifröst Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Terminal agents reach the editor's knowledge through a local Unix socket served by Hulder and a stdio MCP server (`hulder mcp`) that relays each tool call to that socket. No AI inside the editor, no network.

**Architecture:** One new crate `bifrost` runs inside the app: it binds `paths::config_dir()/hulder.sock`, accepts connections on a gpui task, and dispatches newline-JSON requests to a `Bifrost` entity that knows every open `Workspace`. Saga tools are plain file edits under `<project_root>/.hulder/` done by a small self-contained file layer (`saga_files.rs`) that `crates/saga` will replace once merged. The `cli` crate gains an `mcp` subcommand: a synchronous stdio JSON-RPC loop that answers `initialize`, `tools/list`, `tools/call` and `ping`, dialing the socket per tool call. Every accepted connection and tool call is recorded in `hulder_net::NetLog` as `NetEntryKind::Bridge` so the Hollow Back eye shows what asked.

**Tech Stack:** Rust, gpui (`cx.spawn`, `cx.update_window`, `cx.observe_new`), smol 2 for the in-app socket, `std::os::unix::net` for the CLI side, serde/serde_json for every wire, `workspace::Workspace::open_abs_path`, `editor::Editor::go_to_singleton_buffer_point`, `project::Project::diagnostic_summaries`.

**Spec:** `docs/superpowers/specs/2026-10-13-hulder-design.md`, sections 11 and 12.

## Global Constraints

- Socket path: `paths::config_dir().join("hulder.sock")` (`~/.config/hulder/hulder.sock` on macOS). Stale file removed on bind, mode 0600, a symlink at that path refuses to bind. Never TCP.
- Wire: one request per line `{"id": string, "method": string, "params": object}`; reply `{"id","result"}` or `{"id","error":{"code","message"}}`. Several requests per connection are fine; replies are written in order.
- Every path parameter is resolved against the project root, canonicalized (longest existing prefix), and must stay under the project root or `<root>/.hulder/`; anything else answers `forbidden_path`.
- MCP framing: newline-delimited JSON-RPC 2.0 on stdin/stdout, protocol version `2024-11-05`. Notifications (no `id`) get no reply. Tool failures are `isError: true` results, never JSON-RPC errors.
- `crates/saga` does not exist on this branch. `crates/bifrost/src/saga_files.rs` is the stand-in and says so in its header.
- Follow repo CLAUDE.md: no `unwrap()` outside tests, no `let _ =`, no `mod.rs`, `./script/clippy` not `cargo clippy`, keep the README `> [!IMPORTANT]` marker.

## Review Focus

1. Paths: `editor_open` and `saga_read_lore` must refuse `../`, absolute paths outside the root, and symlinks that escape. Tests in Task 2 (`guard::resolve`).
2. Hulder not running: `hulder mcp` must answer every `tools/call` with `isError: true` and the text "Hulder is not running", and `initialize`/`tools/list` must still work so Claude Code does not drop the server. Test in Task 6.
3. Socket hygiene: a stale socket file is removed, a symlink is refused, permissions are 0600. Test in Task 4.
4. Workspace choice: with several windows the request goes to the active window's workspace; dropped workspaces are pruned. Covered by `Bifrost::pick_workspace` logic in Task 5 (manual).
5. `.mcp.json` writer: never follows a symlink, keeps other servers, writes 2-space JSON with a trailing newline. Tests in Task 7.
