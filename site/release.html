What changed

Hulder checks its GitHub releases after opening and daily while running. Use Hulder > Check for Updates for a manual check, or Automatic Update Checks to disable scheduled checks. Preview releases are included.

Choose Download update to fetch the installer. Hulder verifies its SHA256, publisher signature and Apple notarization before revealing it in Finder. Quit Hulder, open the disk image and drag the new app into Applications when ready. Installation and restart remain manual.

Four updater unit tests and native menu checks pass. The automatic check preference was saved and reloaded in both states. Live download verification and rejection of an incorrect checksum pass, including cleanup without removing unrelated files. Kit retains nested project discovery from v0.1.2.

Tested scope

The optimized app builds from public source with patched dependencies. Opening, editing and saving passed in isolated local state. Apple notarization and Gatekeeper verification passed. The dependency audit reports zero blockers across 944 registry packages; eight maintenance notices remain.

These are recorded acceptance results, not a new test run for every website update.
