v0.1.7 release notes

Experimental Apple silicon application download. Source and retained license notices accompany this release. The app keeps internal compatibility version 1.25.0; the public release identifier is v0.1.7.

Download for Apple silicon

What changed

Factory inspection and Open Heimdall now use the ports configured for your selected local controller. The editor context server follows the same controller settings, while explicit local overrides remain available.

This release updates the bundled SQLite engine to 3.54.1 and rustix to 1.1.6 to fix newly reported memory-safety issues. Required project and dependency notices are retained.

Launch and daily update checks and verified installer downloads remain available through the Hulder menu. Installation and restart remain manual.

Tested scope

The optimized build, factory controller and updater tests, factory task checks and database tests passed. The release dependency audit checked 823 registry packages with zero security or unsoundness blockers and ten reviewed maintenance notices. The app and installer passed Developer ID, Apple notarization and Gatekeeper checks.

Acceptance limits

Experimental v0.1.7 Mac release. The Apple silicon download is Developer ID signed, notarized and stapled. A separate clean Mac acceptance remains pending. Manual accessibility acceptance remains pending. The shared editor HTTP client blocks inherited outbound calls; explicit Raven requests, external tools and agents have their own network behavior.

Source publication

Source is available on GitHub. Preserve project and dependency license notices when redistributing. The downloadable Mac app has completed Developer ID signing and Apple notarization.
