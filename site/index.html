Release status

Development preview. Explicit limits.

This project is being prepared for an open source release. The factory includes locally tested execution and UI paths. Broad harness and backend adapters remain experimental pending application specific acceptance. Live exe.dev checks cover remote execution, interactive input and VM restart recovery with a deterministic test agent. A separate authenticated Codex task also passes. Other vendor acceptance remains pending.

This is a static documentation site. It does not connect to your running factory, expose local controls, or show simulated live results.
