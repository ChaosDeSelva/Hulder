What you can do.

Edit with native tools

Use syntax highlighting, language servers, project search, Git views and an integrated terminal in a native editor.

Shape your workspace

Keep project notes in Saga and extend language or appearance support with extensions. Feature add ons use explicit command approval.

Connect agents when you choose

Use Bifrost for editor context, Herdr for terminal sessions and the optional factory inspector for local mission details.

Where it fits.

Hulder is an independently maintained IDE derived from Zed. Editing comes first; factory services are optional. The editor retains upstream licenses and is not affiliated with or endorsed by Zed Industries.

Install Hulder.

Download the signed disk image, drag Hulder to Applications and open it. Use Hulder > Check for Updates for future releases. Launch and daily checks are enabled by default and can be disabled through Automatic Update Checks. Downloads are verified; installation and restart remain manual. Language extensions and language servers are separate. Source build instructions follow.

Apple silicon macOS, Xcode, the pinned Rust toolchain, Python and CMake. See RELEASE.md for full build and signing instructions.

Clone Hulder and run these commands from its root directory.

cargo build --locked -p zed --bin Hulder --features util/debug-embed
