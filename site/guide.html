Hulder setup guide

An independently maintained native IDE with local tools and optional factory integration.

Before you begin

Hulder is an independently maintained IDE derived from Zed. Editing comes first; factory services are optional. The editor retains upstream licenses and is not affiliated with or endorsed by Zed Industries.

Requirements

Apple silicon macOS, Xcode, the pinned Rust toolchain, Python and CMake. See RELEASE.md for full build and signing instructions.

Get the source

git clone https://github.com/ChaosDeSelva/Hulder.git
cd Hulder

Install the Mac app

Download Hulder for Apple silicon, open the disk image and drag Hulder to Applications. This experimental download is Developer ID signed and notarized. Language extensions and language servers are installed separately.

Build and run from source

cargo build --locked -p zed --bin Hulder --features util/debug-embed

Run these commands from the repository root. Keep local state and credentials outside version control.

Complete READMERelease notes

Your first session

  1. Build from source on Apple silicon macOS with Xcode and the pinned Rust toolchain. This command creates a development build, not a signed distribution.
  2. Launch ./target/debug/Hulder and open a local project. Install the hulder CLI from the application menu if you want terminal access.
  3. Install the language servers you need on your PATH. Syntax support and language server features depend on the language configuration and installed extensions.
  4. Add Bifrost, Herdr or a local factory connection only when needed. You can use the editor without starting the factory.

Operating boundaries

The v0.1.1 Mac download is signed and notarized; separate clean Mac acceptance remains pending. Manual accessibility acceptance remains pending. The shared editor HTTP client blocks inherited outbound calls; explicit Raven requests, external tools and agents have their own network behavior.
