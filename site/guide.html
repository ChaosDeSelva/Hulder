Project guide

An independently maintained native IDE with local tools and optional factory integration.

Requirements

Apple silicon macOS, Xcode, the pinned Rust toolchain, Python and CMake. See RELEASE.md for full build and signing instructions.

Build and run

cargo build --locked -p zed --bin Hulder --features util/debug-embed

Run these commands from the repository root. Read the complete README for authentication, configuration, service ports and operating limits.
